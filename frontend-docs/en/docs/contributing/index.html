Contributing

The current project lives in Jolt. Review the code, open issues, and propose changes at github.com/Escobarq/jolt.

Name transition: these docs use the future Joltv brand, while the repository, source code, and executable are still named jolt. The rename will happen later.

Current repository

Clone the original repository and work from its root:

git clone https://github.com/Escobarq/jolt.git
cd jolt

Main areas include:

  • src/: Rust CLI implementation.
  • tests/: integration tests, when available.
  • docs/: technical documentation and module records.
  • openspec/: specifications and planned changes.

Before you start

  • Read the repository README and specifications in openspec/specs/.
  • Search existing issues and pull requests before opening a new one.
  • For larger changes, describe the goal, impact, and validation strategy first.

Validate changes

cargo fmt --check
cargo test
openspec validate --all

Run Rust commands from the repository root. If you change code or documentation structure, regenerate the graph from the root:

graphify update .

Document a feature

  1. Explain the problem and expected workflow.
  2. Add a minimal copy-paste example.
  3. Document related errors, requirements, and flags.
  4. Include the version or experimental status where relevant.

Site pages live in en/ and es/. Keep both versions synchronized and use the shared layout.
