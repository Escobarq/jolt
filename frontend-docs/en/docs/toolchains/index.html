JDK

Joltv reuses the Java tools already installed on your machine and only downloads a JDK when you explicitly allow it.

Discovery order

  1. GRAALVM_HOME and JAVA_HOME.
  2. The javac executable on PATH, also validating java.
  3. Standard system locations such as C:\Program Files\Java, /usr/lib/jvm, or macOS installations.
jolt check

Version compatibility

The major version declared in [project].java_version is compared with available JDKs. An equal or newer compatible installation can be reused.

ConfigurationResult
java_version = "21"Looks for JDK 21 or a compatible newer version.
No compatible JDKReports the requested version and inspected locations.

Explicit downloads

Joltv never downloads JDKs silently. Explicitly allow a Temurin download with the flag:

jolt build --download-jdk
jolt run --download-jdk
jolt test --download-jdk
