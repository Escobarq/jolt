Configuración

El archivo jolt.toml describe la identidad del proyecto, la versión de Java, sus dependencias y cómo se empaqueta.

Recomendación: conserva jolt.lock en control de versiones para repetir exactamente las resoluciones.

Manifiesto mínimo

[project]
name = "mi-aplicacion"
version = "1.0.0"
java_version = "21"
main_class = "com.example.App"
package = "com.example"

[dependencies]
"com.google.code.gson:gson" = "2.14.0"
CampoDescripción
nameNombre del proyecto y valor predeterminado para artefactos.
versionVersión usada por builds y paquetes.
java_versionVersión mayor de JDK requerida; por defecto se usa Java 21.
main_classClase con el método main de la aplicación.
packageNamespace Java raíz para plantillas y scaffolding.

Dependencias

Las coordenadas siguen el formato Maven groupId:artifactId y opcionalmente una versión.

[dependencies]
"org.apache.commons:commons-lang3" = "3.17.0"
"org.openjfx:javafx-controls" = "21.0.2:windows"

[dev-dependencies]
"org.junit.jupiter:junit-jupiter-api" = "5.11.0"

Las dependencias normales se incluyen en el runtime. Las de desarrollo se reservan para pruebas y herramientas.

Empaquetado

[package]
type = "nsis"
name = "MiAplicacion"
dest = "dist"

[package.windows]
upx = true
add_to_path = true
desktop_shortcut = true
