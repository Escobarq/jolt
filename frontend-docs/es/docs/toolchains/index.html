JDK

Joltv intenta reutilizar las herramientas Java que ya tienes instaladas y solo descarga un JDK cuando lo autorizas explícitamente.

Orden de búsqueda

  1. GRAALVM_HOME y JAVA_HOME.
  2. El ejecutable javac en el PATH, validando también java.
  3. Rutas estándar del sistema, como C:\Program Files\Java, /usr/lib/jvm o las instalaciones de macOS.
jolt check

Compatibilidad de versiones

La versión mayor declarada en [project].java_version se compara con los JDK disponibles. Una versión instalada igual o superior puede reutilizarse cuando es compatible.

ConfiguraciónResultado
java_version = "21"Busca JDK 21 o una versión posterior compatible.
Ningún JDK compatibleSe muestra un error con la versión solicitada y las rutas revisadas.

Descarga explícita

Joltv no descarga JDKs silenciosamente. Autoriza la descarga de Temurin con el flag correspondiente:

jolt build --download-jdk
jolt run --download-jdk
jolt test --download-jdk
