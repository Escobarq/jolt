Jolt · Guía

Contribuir

El proyecto actual vive en Jolt. Puedes revisar el código, abrir issues y proponer cambios desde github.com/Escobarq/jolt.

Nota sobre el nombre: esta documentación usa la marca futura Joltv, pero el repositorio, el código y el ejecutable todavía se llaman jolt. El renombrado se hará posteriormente.

Repositorio actual

Clona el repositorio original y trabaja desde su raíz:

git clone https://github.com/Escobarq/jolt.git
cd jolt

Las áreas principales son:

  • src/: implementación Rust del CLI.
  • tests/: pruebas de integración, cuando estén disponibles.
  • docs/: documentación técnica y registros de módulos.
  • openspec/: especificaciones y cambios planificados.

Antes de empezar

  • Revisa el README del repositorio y las especificaciones en openspec/specs/.
  • Busca issues y pull requests existentes antes de abrir uno nuevo.
  • Para cambios grandes, describe primero el objetivo, el impacto y la estrategia de validación.

Validar cambios

cargo fmt --check
cargo test
openspec validate --all

Ejecuta los comandos de Rust desde la raíz del repositorio. Si actualizas código o documentación estructural, regenera también el grafo desde la raíz:

graphify update .

Documentar una funcionalidad

  1. Explica el problema y el flujo esperado.
  2. Añade un ejemplo mínimo que se pueda copiar.
  3. Documenta errores, requisitos y flags relacionados.
  4. Incluye la versión o el estado experimental cuando corresponda.

Las páginas del sitio viven en es/ y en/. Mantén ambas versiones sincronizadas y usa el layout compartido.
