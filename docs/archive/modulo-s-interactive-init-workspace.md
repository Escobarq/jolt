# Modulo S: Asistente Interactivo de Inicializacion

**Responsabilidad:** Guiar la creación de proyectos mediante menús interactivos en consola.

### Funcionalidades implementadas:
- Selección interactiva entre Proyecto Individual y Workspace Monorepo.
- Solicitud asistida de nombre de paquete con sugerencias contextuales.
- Detección automática del workspace padre para autorregistro de miembros en `[workspace].members`.
