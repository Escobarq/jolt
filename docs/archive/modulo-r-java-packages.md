# Modulo R: Paquetes Java y Namespaces Estructurados

**Responsabilidad:** Administrar la estructura canónica de paquetes de Java (`package org.equipo.proyecto;`) en proyectos y submódulos.

### Funcionalidades implementadas:
- Generación de directorios anidados (`src/main/java/org/equipo/proyecto/` y `src/test/java/org/equipo/proyecto/`).
- Inyección dinámica de cabeceras de paquetes en todas las plantillas.
- Configuración en manifiesto: campos `package` y `group_id`.
